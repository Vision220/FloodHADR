# PHASE 21 — SCIENTIFIC REPORT GENERATION

## 1. Executive Summary & Overview
The **Scientific Technical Report Engine** in FloodHADR generates comprehensive, standardized, reproducible technical reports for every dam break simulation run. 

Reports can be exported as structured JSON objects or rendered into GitHub-Flavored Markdown documents for publication, archiving, or disaster management reporting. Each report embeds a complete, deterministic execution configuration payload (`reproducibility_config`) allowing any simulation run to be perfectly reproduced.

---

## 2. Mandatory Technical Report Sections
Every report generated by `ScientificReportGenerator` contains the following 25+ structured sections:

1. **Scenario Metadata**: Scenario ID, Run ID, Model ID, Model Version, DEM Version, HEC-RAS Version, UTC Timestamp, Platform Metadata.
2. **Study Area**: Location name, coordinates, river basin, catchment surface area ($km^2$), and min/max elevation bounds ($m$).
3. **Data Sources**: Lineage of satellite SAR, digital elevation models, CWC telemetry gauge records, and IMD rainfall datasets.
4. **Digital Elevation Model (DEM)**: DEM dataset ID, resolution ($m$), vertical datum, and coordinate reference system (CRS).
5. **Dam Parameters**: Dam name, construction type, structural height ($m$), crest length ($m$), spillway design discharge ($m^3/s$).
6. **Reservoir Parameters**: Full Reservoir Level ($z_{\text{FRL}}$), Minimum Drawdown Level ($z_{\text{MDDL}}$), active pool level ($m$), gross storage capacity ($\text{Mm}^3$).
7. **Weather**: Catchment precipitation intensity ($mm$), storm duration ($hours$), rainfall product type.
8. **Hydrology**: Peak inflow hydrograph ($Q_{\text{in}}$ in $m^3/s$), return period, runoff coefficient.
9. **Breach Configuration**: Failure mode (`OVERTOPPING`, `PIPING`, `PARTIAL`, `RAPID`, `SLOW`, `USER_DEFINED`), breach width ($B_{\text{avg}}$), formation time ($t_f$), invert elevation ($z_{\text{invert}}$), peak outflow ($Q_{\text{peak}}$).
10. **2D Model**: Governing hydrodynamic equations (`FloodHADR SWE` / `FloodHADR DWE`), numerical discretization scheme, time step ($\Delta t$), Courant number.
11. **HEC-RAS Model**: Equivalent HEC-RAS solver formulation (`HEC-RAS 6.4.1 2D SWE` / `DWE`) and grid alignment status.
12. **Mesh**: Resolution option (`FINE_5M`, `MEDIUM_12M`, `COARSE_30M`), cell count, cell size ($m$), breaklines, refinement regions.
13. **Boundary Conditions**: Upstream inflow hydrograph $Q(t)$, downstream boundary condition (`FREE_OUTFLOW`, `NORMAL_DEPTH`, `RATING_CURVE`).
14. **Manning's Roughness ($n$)**: Channel roughness ($0.035$), floodplain roughness ($0.055$), urban roughness ($0.080$).
15. **Simulation Results**: Peak hydraulic parameters ($h_{\text{max}}$, $v_{\text{max}}$, $t_{\text{arr}}$, $A_{\text{flood}}$).
16. **Maximum Depth**: Peak flood depth across downstream valley ($m$).
17. **Maximum Velocity**: Peak flow velocity ($m/s$).
18. **Arrival Time**: Initial flood wave arrival time at critical assets ($minutes/hours$).
19. **Flood Area**: Total geographical surface inundation extent ($km^2$).
20. **Model Comparison**: Scientific comparative metrics against HEC-RAS and alternative solvers (RMSE, MAE, IoU, F1).
21. **Validation**: Objective goodness-of-fit metrics (RMSE, MAE, NSE, KGE, Peak Error, Timing Error, IoU, F1) and strict status classification (`VALIDATED`, `PARTIALLY_VALIDATED`, `UNVALIDATED`, `SCENARIO`, `EXPERIMENTAL`, `DEMO`).
22. **Sensitivity**: Sensitivity indices across 7 core physical and numerical parameters.
23. **HADR Impact**: Affected human population, flooded infrastructure count, blocked road segments, safe evacuation zones.
24. **Limitations**: Spatial DEM limitations, friction uniformity assumptions, breach empirical kinetics.
25. **Provenance & Reproducibility**: Cryptographic lineage hash, authoring platform metadata, and deterministic configuration payload.

## 5. REST API Integration

- `GET /api/reports/simulation/{sim_id}`: Returns the full structured JSON scientific technical report.
- `GET /api/reports/simulation/{sim_id}/markdown`: Generates downloadable GitHub-Flavored Markdown report (`.md`).
- `POST /api/reports/generate`: Generates report payload for custom scenario parameter inputs in JSON or Markdown format.
