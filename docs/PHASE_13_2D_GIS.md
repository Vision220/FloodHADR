# PHASE 13 — 2D FLOOD GIS UPGRADE

## Executive Summary

Phase 13 delivers a major upgrade to FloodHADR's 2D GIS Mapping Engine (`frontend/src/components/map/GISMapModule.tsx` & `backend/app/gis/gis_2d_service.py`). The map eliminates static flood polygons and dynamically consumes time-series **`SimulationFrame`** snapshots generated by FloodHADR's hydraulic solvers or imported from HEC-RAS.

The GIS interface integrates a 17-layer interactive map stack, dynamic model selection (`FloodHADR SWE`, `FloodHADR DWE`, `HEC-RAS SWE`, `HEC-RAS DWE`), interactive timeline controls (`T+0` to `T+360`), and real-time spatial difference overlays.

---

## Dynamic `SimulationFrame` Consumption Mandate

> [!IMPORTANT]
> **NO STATIC FLOOD POLYGONS**
> 
> The 2D map does **NOT** render static pre-cooked flood extents. Every hydraulic visual layer (Depth, Velocity, Arrival Isochrones, Submergence Footprint, Spatial Difference Grid) is dynamically computed and updated in real time as the user advances the timeline or changes the active hydraulic model.

## Timeline & Model Selector Controls

### 1. Timeline Controls
- Discrete timeline step selector buttons:
  $$\mathbf{T+0},\, \mathbf{T+5},\, \mathbf{T+10},\, \mathbf{T+30},\, \mathbf{T+60},\, \mathbf{T+120},\, \mathbf{T+180},\, \mathbf{T+240},\, \mathbf{T+360} \text{ mins}$$
- **Interactive Behavior:** Moving the timeline slider or selecting a step updates the active `SimulationFrame` hydraulic state across all wetted cells, updating depth, velocity, arrival time, population at risk, and submerged infrastructure indicators instantly.
- Play/Pause animation button for automated timeline progression.

### 2. Model Selector Controls
Allows switching between four active model drivers on the 2D map canvas:
- **`FloodHADR SWE`**: Native Full 2D Shallow Water Equations
- **`FloodHADR DWE`**: Native 2D Diffusion Wave Equation
- **`HEC-RAS SWE`**: Imported USACE HEC-RAS 2D Full Momentum
- **`HEC-RAS DWE`**: Imported USACE HEC-RAS 2D Diffusion Wave

Switching models dynamically updates the active layer results and recalculates spatial difference overlays relative to reference models.

## REST API Integration

The 2D GIS engine exposes two REST API endpoints in FastAPI:

- **`GET /api/v1/gis/layers`**: Returns the complete manifest of all 17 GIS map layers, supported model drivers, and available timeline steps.
- **`POST /api/v1/gis/frames`**: Returns dynamic GeoJSON layer features and simulation frame metrics for any chosen model and timeline step.

```json
{
  "model_name": "FloodHADR SWE",
  "time_step_min": 30,
  "breach_width_m": 180.0,
  "reservoir_level_m": 830.0
}
```
